# CRUD em PHP

**IFAC · Técnico em Informática para Internet (TIPI)** · 2º ano · Programação Web · 2022

Introdução ao CRUD (criar, listar, editar e excluir) em PHP com PDO e MySQL.

| Pasta | |
|---|---|
| `php/` | Versão final |
| `php-incorreto/` | Versão com erros, usada como exercício de correção |
| `php-corrigido/` | A mesma versão depois de corrigida |

## Como rodar

1. Crie um banco MySQL `test` (credenciais em `php/config.php`).
2. `php -S localhost:8000 -t php` e abra http://localhost:8000
